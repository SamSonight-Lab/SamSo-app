顔 · 声 · 歌う
  1. Mond nauwelijks open = zacht, verder open = harder. De vorm van je mond kleurt de klank.
  2. Knikken omhoog/omlaag = toonhoogte. Hoofd buigen links/rechts = DJ-filter.
  3. Elk masker heeft een eigen stem: TENGU verfijnd, ONI demon, KITSUNE geest, ROBOT spraakcomputer, MONK keelzang, HEAVEN koor, CHAOS chaos, en SAMPLE: koor, mellotron, kat, V8, wind, golven, merel… of je eigen opname.
  4. Lachen = majeur koortje, mondhoeken omlaag = mineur. Wenkbrauwen = vibrato, wangen bol = grom.
  5. Neus optrekken = fuzz, mond opzij = metaal, ogen wijd = shimmer, lippen persen = crush.
  6. Ogen dicht = noot vasthouden, knipoog = octaaf omhoog/omlaag, snel nee schudden = stutter.
