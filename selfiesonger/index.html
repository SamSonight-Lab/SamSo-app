  1. Houd je iPhone recht voor je gezicht, met goed licht erop.
  2. Mond open = geluid. Vorm je mond: tuiten "oe", lachen "ie", wijd "aa".
  3. Hoofd kantelen links/rechts = toonhoogte.
  4. Lachen = majeur koortje, mondhoeken omlaag = mineur. Wenkbrauwen omhoog = vibrato, wangen bol = grom, ogen dicht = noot vasthouden, hoofd schudden = stotteren.
  5. De eerste 2 seconden neutraal kijken: dan leert hij je rustgezicht. Opnieuw met CAL.
